무료 웹 드론 시뮬레이터

해양·육상·공중 무인 이동 수단을 조종하는 무료 웹 게임. 자동 기기 성능 등급, 키보드와 듀얼 조이스틱, 1인칭·3인칭 시점, 위치 기반 주변 명소, 다국어를 지원하며 Google 실경 서비스도 설정할 수 있습니다.

휴대전화와 컴퓨터에서는 어떻게 조작하나요?

컴퓨터에서는 W/S/A/D와 방향키를 사용합니다. 휴대전화와 태블릿에서는 화면의 듀얼 스틱 또는 방향키를 사용합니다.

실제 공역 지도인가요?

시뮬레이션 경관은 실제 측정한 지형이 아닙니다. Google 지표 실경에는 API 키와 지역 지원이 필요하며 수중 생태는 시뮬레이션입니다.
