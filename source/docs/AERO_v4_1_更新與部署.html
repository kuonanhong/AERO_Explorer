AERO Explorer 4.1
手機修正、附近照片與移動視差

本包可直接部署到 kuonanhong.github.io/AERO_Explorer/，保留 22 種介面語言、海陸空載具、鍵盤與觸控操控。

本次修正

問題現在的行為
LINE 顯示 Google 地圖 ERR_BLOCKED_BY_RESPONSE預設改用可見範圍的 OpenStreetMap 街道圖磚，不再載入被擋的 Google consumer iframe。附近景點與载具座標標記在網頁內呈現，另保留正式 Google Maps 連結。
LINE 不支援下載，遊戲卻說已下載拍照先開啟 PNG 預覽，不自動觸發下載。長按可用時可儲存；支援檔案分享的瀏覽器會顯示分享按鈕。一般瀏覽器另有手動 PNG 下載。提示區分「照片已產生」「提出下載要求」「交給分享功能」，不假裝確認寫入相簿。
附近景點只有文字附近卡片加入對應照片、來源與授權。高雄長庚使用明確標為 2013 年院內咖啡店的歷史照片，不當成醫院外觀，也不投影為飛行背景。其他地區的百科景點按需核對 Commons 照片授權，查無合格圖片會說明。
前進時照片固定WebGL 和 Canvas 都加入照片估計深度：近景移動較大，前進擴張、後退收縮、橫移方向相反；360°照片保留轉頭觀看。水下的生成訓練背景也加入移動視差，魚群等物件維持三維投影。

照片視差是 2.5D 估計，並非 Google 衛星影像、即時攝影或實測立體地形。照片沒有拍到的背面不能還原；接近估計的移動範圍時，下方會提示重置或換視點。水下魚群、礁石與背景屬模擬，不宣稱是所選湖泊或海域的真實水底。標記座標是從定位起點推算的遊戲位置。

手機使用方式

  1. 允許定位後選附近景點，或在搜尋框輸入目的地；拒絕定位仍能用明確標示的示例位置。
  2. 按「開始」，兩手搖桿分別控制升降／轉向與前後／橫移。畫面文字與功能鍵留在飛行視野下方。
  3. 按「拍照」會暫停並顯示照片。先嘗試長按圖片或「分享／儲存照片」。
  4. LINE 若沒有儲存選項，使用右上角選單在 Safari 或 Chrome 開啟同一網址，再拍照。內建瀏覽器的作業系統限制不能由 HTML 強制解除；手機螢幕截圖仍可使用。

LINE 的下載按鈕會隱藏，避免反覆觸發截圖中的錯誤。分享支援以瀏覽器實際能力判斷，取消分享不報成功；分享失敗保留照片預覽。

已有 AERO_Explorer 儲存庫：更新指令

以下為 macOS／Linux／Git Bash。路徑請換成自己解壓縮的實際位置。先確定終端機在 AERO_Explorer 儲存庫；如果停在 git diff 的分頁畫面，按 q 回到命令列。Ctrl+C 可中斷一般命令。

cd ~/AERO_Explorer
git status
git remote -v

如果 status 有自己的未提交修改，先把要保留的內容 commit；不要直接 reset --hard 或清除檔案。確認乾淨後：

git switch main
git pull --ff-only origin main
cp -R ~/Downloads/AERO_Drone_Web_FullPackage_v4_1/AERO_Explorer/. .
git --no-pager diff --stat
git status --short
git add .
git --no-pager diff --cached --stat
git commit -m "Fix mobile maps and photos; add nearby imagery and motion parallax"
git push origin main

git diff 只查看差異；git add → git commit → git push 才會送到 GitHub。git pull 是從 GitHub 取回更新。上方複製方式保留既有其他檔案，不會刪除歷史版本資料夾。

第一次下載儲存庫

git clone https://github.com/kuonanhong/AERO_Explorer.git
cd AERO_Explorer

接著執行上面的複製、diff、add、commit、push。登入驗證依 GitHub 提示使用 HTTPS credential manager、個人存取權杖或 SSH；不要把權杖写入 HTML 或提交到儲存庫。

啟用 GitHub Pages

  1. 開啟儲存庫 Settings → Pages。
  2. 若使用 Deploy from a branch，選 main 與 /(root)，按 Save。
  3. 等待 Pages 建置完成後開啟 遊戲網址。
  4. 手機若仍顯示舊版，重新整理；必要時關閉原分頁後重開。版本在頁尾標為 4.1。

若儲存庫已用 GitHub Actions 部署，保留原工作流程並讓其發布新的根目錄內容，或使用 source/dist 作為部署輸出。不要將整個完整 ZIP 上傳當作網頁；GitHub Pages 不會自動解壓縮。

從原始碼重建

cd source
npm ci
npm test
npm run build
npm run export:github
npm run export:smartaction

輸出分別為 .aero-output/AERO_Explorer/ 與 .aero-output/SmartAction/games/aero/。直接發布資料夾時不需要 Node.js；Node 只供修改與建置。

地圖與大量使用者

主模擬在每位玩家自己的裝置運行。沒有共享多人世界伺服器，也沒有完成十萬人同時上線的負載測試；GitHub Pages、地圖與百科 API 的容量必須分別評估。

公共 OpenStreetMap 圖磚不提供十萬人流量的容量保證。地圖只在可見時載入、最多保留 9 張可見圖磚、同時最多 3 個請求，不批次預抓或離線快取。大量公開流量前，請換成容量合適的圖磚業者或自架服務，在 config.js 設定 mapTileURL、mapAttribution、mapAttributionURL；保持正確授權標示。單檔版本須重新建置才能更改內含設定。

Google 地圖外開連結不需要玩家填 API key。如網站擁有者要使用正式嵌入服務，需自行設定 googleEmbedKey 與 mapMode:'google'；進階 Google 3D／Street View 仍需要適用 API、擁有者金鑰與服務條件。這次修正沒有繞過 Google 的嵌入限制或下載 Google 影像。
