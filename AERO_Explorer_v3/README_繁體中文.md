# 翱翔 AERO Explorer v3：海陸空無人載具網頁遊戲

在自己的瀏覽器練習飛行、陸地行駛與水下探索，使用鍵盤、雙手觸控搖桿或畫面方向鍵。支援第一人稱 FPV、第三人稱、三種難度、光環任務與模擬照片下載；提供22種介面語言及13處高雄地點的22語介紹。原有網頁套件為修改基準，Unity Windows版及Phoenix只作功能參考。

## 快速開始

- 直接開啟 `dist/standalone.html`：完整程式、3D引擎、樣式、字典、景點與原創海洋圖片均內嵌。遊戲本身可離線執行；定位需安全來源和許可，Google實景及天氣需網路。手機請使用網站網址，部分檔案管理器的HTML預覽器不執行JavaScript。
- 一般網站：發布整個 `dist/`，保留相對目錄。`dist/index.html` 是入口，不要只上傳ZIP。
- 本機測試：`python3 -m http.server 8080 --directory dist`，開啟 `http://localhost:8080`；Windows可用 `py -m http.server 8080 --directory dist`。
- 修改與重建：Node.js 22或較新版本，`npm ci`、`npm run build`、`npm test`。本次使用Node24.19.0。正式靜態網站不需執行Node或Python。

**完整GitHub命令、大檔管理、Google設定、CDN規劃及驗證步驟，見 `README_GitHub_與大量流量部署.md`。**

## 操控與三種載具

| 手／按鍵 | 空中 | 陸地 | 水下 |
|---|---|---|---|
| 左手上／W | 升高；挑戰模式增加油門 | 不改變高度 | 上浮 |
| 左手下／S | 下降；挑戰模式減少油門 | 不改變高度 | 下潛 |
| 左手左右／A、D | 向左、右旋轉 | 向左、右旋轉 | 向左、右旋轉 |
| 右手上下／↑、↓ | 前進、後退 | 前進、後退 | 前進、後退 |
| 右手左右／←、→ | 橫移 | 橫移 | 橫移 |

第一次開啟先顯示雙手教學，按「了解，開始練習」才開始。手機及平板自動顯示雙搖桿，也可選兩組虛擬方向鍵；這是能同時多點觸控的遊戲鍵盤。V切換视角，空白鍵暫停，R重置。失焦或分頁隱藏會暫停並清除輸入。

入門模式協助定高、回正和煞車；進階保留較多慣性；挑戰以簡化推力、重力及阻力模擬手動油門。這是回中油門配置，並非實體RC遙控器的非回彈油門。原有七個光環及返航降落任務保留，陸地、水下與Google實景使用自由探索。模擬陸地有簡單障礙物碰撞；Google實景沒有實際建物碰撞或道路導航。

探索水平範圍為原點各向約1公里；空中上限500公尺，水下深度0.4–20公尺。物理值為遊戲訓練設計，不是實際載具規格。照片按鈕下載**模擬畫布PNG**；Google實景視窗請使用系統截圖，不能把模擬照片當成地圖供應者的實景照片。

## 開啟前硬體分級與執行時保護

先讀取瀏覽器提供的粗略記憶體、CPU核心提示、觸控資訊與WebGL能力，再執行小型圖形探測。

| 版本 | 適用情況 | 渲染預算 |
|---|---|---|
| 輕量版 | 無WebGL、低記憶體／核心提示或慢探測 | Canvas2D、30FPS目標、1倍像素比；不下載3D模組 |
| 標準版 | 手機、硬體資訊不完整或中等裝置 | WebGL、45FPS目標、1倍像素比、較少樹木／魚群 |
| 完整版 | 可用提示與圖形探測較佳的桌機 | WebGL、60FPS目標、最高1.5倍像素比、較多生態物件 |

可手動切換版本，持續低FPS時仍會自動降級；當前WebGL畫布資源中斷時切至Canvas2D。使用實例化網格、共享幾何、限制繪圖像素、5Hz資訊面板、暫停5Hz重繪、固定120Hz物理且每影格最多8步。没有重型動態陰影、逐像素水面求解或即時AI推論。

瀏覽器**不能可靠測出剩餘RAM、可用VRAM或所有CPU/GPU規格**，Safari等平台可能不提供記憶體提示。分級是保守估計及執行時回饋，不能保證所有裝置不當機。現代macOS、Windows、Linux、iPhone、Android及平板瀏覽器可使用；古老iPod touch或停更瀏覽器不保證可執行。詳見 `DEVICE_PROFILES.md`。

## GPS、附近地點、Google地表實景

「使用目前位置」在使用者允許後取得一次瀏覽器定位，顯示座標與誤差，再依距離整理內附地點。它不是持續追蹤，也不能保證GPS沒有偏差。可手動設定緯度、經度及地理原點海拔。預設高雄座標只是**示例**，不是已偵測到您的位置或濱山街精確位置；原點海拔20公尺是可調的估計MSL，不是測量地形高度。

13個內附地點包括澄清湖、高雄長庚、果嶺自然公園、鳥松濕地、衛武營、大東、鳳儀書院、曹公廟、黃埔新村、科工館、鳳山龍山寺、金獅湖及西子灣。顯示名稱、簡短介紹、距離與官方來源；資料查核日期2026-10-07，座標為地圖示意點。不同位置排序不同，西子灣不會被宣稱就在濱山街旁。這些介紹不是即時開放資訊，也不是現實飛行許可。詳見 `PLACE_SOURCES.md`。

`dist/geo.js` 提供Google Maps JavaScript的3D地圖、Street View及Places Nearby Search介面。開啟Google實景需要您自己的**網站與API限制的瀏覽器金鑰**、對應API、帳單、額度及區域覆蓋。無金鑰仍可玩完整模擬場。本套件沒有附第三方金鑰，沒有替您註冊帳號或啟用計費；本次對Google服務驗證的是官方介面契約與測試替身，沒有驗證付費實景載入或每個高雄地點的3D覆蓋。

設定 `dist/config.js` 的 `googleMapsKey` 後重建網站，或在頁面地圖設定暫時輸入。設定中的金鑰是公開瀏覽器用途，務必做網址與API限制；不要放後端secret。頁面暫時輸入的金鑰只存在記憶體。`autoNearby:true` 會在GPS成功後自動查Google附近地點，否則由玩家按搜尋按鈕。Places即時結果只顯示名稱／地址／來源，不憑空補歷史。

Google3D隨模擬位置及視角移動相機；Street View在供應者已有照片點間移動，不能當成連續空拍。地圖影像不是即時攝影。Google視窗保留供應者及第三方標示；Service Worker不攔截或快取Google圖資。民航局入口仍提供官方網頁，沒有嵌入即時禁限航區。

## 水下與天空的寫實界線

海洋練習場含原創AI海洋背景、程序魚群、礁石及珊瑚；淡水湖泊模式含魚、石底與水草，排除海洋珊瑚及海洋背景。鳥群及雲朵為程序模型。詳見 `REEF_PROVENANCE.md`。

**水下不是Google提供的實測湖底／海底，也没有該地点的即時魚群、鳥群、雲層或建物內部資料。** Google地表實景與訓練生態是分開的資料來源；選擇水下時會切回明確標示的模擬場。陸上地點沒有已知水域時使用獨立海洋練習場，不能聲稱医院或博物館下方存在礁石。

## 天氣與大量訪客

預設使用模擬風，不會在每位玩家開場時呼叫免費氣象服務。`backend/weather-worker/` 是可選Cloudflare Worker範例，依約1公里網格共用15分鐘快取，逾時或供應者失效時可返回標示STALE的舊參考資料。需由您自行配置、部署、選用合法服務計畫，再設定 `weatherEndpoint`。天氣參考顯示資料時間及Open-Meteo／CC BY4.0標示；風場仍為簡化遊戲模型。這不是現場感測或各高度氣流。

10萬位訪客各自模擬可避免把飛行物理放在網站伺服器，仍需要足夠的靜態下載、CDN、來源保護及外部API額度。沒有實作共享世界、互看其他玩家、聊天室或同步伺服器。**没有進行10萬人連線測試，也没有零延遲、零當機或GitHub Pages容量保證。** GitHub Pages有1GB網站及100GB/月軟流量上限；正式大量流量應選可配置容量的CDN／靜態託管，Google及天氣另計配額。

各語言有獨立可爬取HTML、canonical、hreflang、FAQ／VideoGame JSON-LD，另有Sitemap、robots.txt與llms.txt。搜尋收錄、排名及AI搜尋採用不保證。換網域或GitHub子路徑時設定 `AERO_ORIGIN=https://USER.github.io/REPO` 重建，再用自己的站點驗證權限提交Search Console。
